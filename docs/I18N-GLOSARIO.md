# Glosario i18n (DP-10, CONTEXTO-72 §4)

Base para traducir `en` y `ht` de forma consistente en todo el repo. Cualquier
término nuevo que se decida durante el cableado (F3-F5) se agrega aquí.

**Estilo por idioma:**
- **Inglés**: internacional neutro, trato de "tú" → *you*, mayúscula de oración,
  verbos en imperativo en botones ("Save", no "Saving").
- **Kreyòl ayisyen**: ortografía oficial (OFÒ), sin calcos del francés cuando
  existe palabra criolla propia, trato informal ("ou"). **Es traducción
  generada por Claude, no validada por un hablante** — ver
  [`docs/I18N-REVISAR-HT.md`](./I18N-REVISAR-HT.md) y el paso físico 3 de
  `CONTEXTO-ACTUALIZACION-72.md`.

**Nombres propios que NUNCA se traducen:** SGC, CSD App, Constructora SD,
Compa, Claude, Odoo, WhatsApp, Supabase, `RD$`.
